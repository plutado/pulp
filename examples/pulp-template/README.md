# Starter template

The folder the authoring guide ([`docs/template-authoring.md`](../../docs/template-authoring.md)) builds step by step: a lower third with a bar, two lines of type that ride it, a logo slot, and a hold that stretches to any length.

Copy this folder into one of your library folders, change the `id` in `template.json` to something you own (`yourname.lower-third`, say), and Pulp indexes it on the next scan. It is CC0: no rights reserved, so start from it freely.
