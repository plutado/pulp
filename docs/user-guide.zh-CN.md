# 使用 Pulp

窗口里有什么、如何用它制作内容，以及值得了解的按键和搜索词。可从 **帮助 → 用户指南** 打开，也可从开始屏幕的 **学习** 打开。

Pulp 用模板制作动态图形，并把文件交给你用来完成作品的任何软件。一切都在你的电脑上运行：无需帐户，无需上传，无需网络。

## 窗口

从左到右共七个区域：

- **浏览面板。** 素材库工具（添加、重新扫描、带麦克风选择器的录制按钮，以及摄像头按钮）下方有两个分区。顶部是 **搜索** — 搜索框、其下方的范围标签、筛选标签（模板、视频、图像、音频、竖屏、Alpha、收藏），以及“用途…”和“风格”筛选菜单。其下方是 **浏览** — 按类型划分的树：下方字幕条、标题和片头、片尾卡、配套组合、背景、叠加和边框、转场和擦除、设计元素、效果、物品、库存视频、照片和静态图、音乐、音效，然后是快速访问和我的文件夹。选择一个节点会将一切 **限定** 在该范围内；范围标签会显示这一点，点按其 × 即可重新扩大范围。“浏览”标题中的漏斗会在你输入时筛选树本身。
- **舞台。** 画面，且只有画面：以“输出”标签页设置的形状和尺寸，按你的设置实时预览模板。点按一行文字或一个标志即可选择它，拖移以移动，拖移角以缩放，用箭头键微调。右键点按可进行图层编辑、添加文本、形状或素材，以及设置舞台自身的背景。舞台角落四个按钮中的第一个显示透明图形背后的内容 — 棋盘格、黑色、白色、灰色或自选颜色 — 并可打开选择器选择其他背景。
- **空白画布**（文件 → 新建空白画布，Cmd/Ctrl+Shift+N）是一个自身不绘制任何内容的模板：一个覆盖整帧的开放块，用于从零开始构图。文本、**形状**（矩形、椭圆或三角形，带颜色、尺寸和宽高比）、图片和片段都作为图层放在上面 — 用舞台的控制柄放置和调整大小，用每个图层自己的开始、结束、入场和出场来设定时间 — 你构图的内容会像其他作品一样存储在项目中。构图中的任何属性 — 一行文字、一种颜色、一张图片 — 只要选取它（在舞台上右键点按，或点按其卡片上的选取按钮）并命名，就会成为 **模板参数**：它会出现在“参数”标签页顶部的 **模板参数** 下，其控件可编辑它所命名的属性。画布上的每个图层一开始都会淡入淡出；右键菜单中的 **动画**（或图层卡片上的 **动画**）可为其赋予现成的动态效果 — 滑入、升起、弹出、擦入、飘过、脉动、旋入 — 写成普通的入场、出场和关键帧，之后可以编辑；同一菜单中的 **录制关键帧** 会为所选图层开启关键帧录制。布局按形状分别保存 — 切换“输出”标签页的画面比例，即可为竖向画面单独布局 — 而 **将此布局用于所有形状**（在图层的“高级”分区中）会把屏幕上的布局交给尚未布局的形状。准备就绪后，**文件 → 存储为模板…** 会将构图以开放格式写为模板文件夹：选取的参数成为它真正的参数，该文件夹立即加入素材库，新模板会重新打开以供编辑 — 也可以在文本编辑器中打开，因为它与所有模板采用相同的格式。所选的图片、片段或声音不会保留（模板从不包含素材库 ID）；该图层存储为空，留待下一位使用者填充。
- **结果。** 卡片网格或行列表，其标题中有数量、所选类别的说明，以及排序、视图和大小控件。卡片在缩略图角落显示项目时长（0:04），以标签显示分辨率（HD、Full HD、4K，或高度，如 1440p — 确切像素见其工具提示），然后是表示透明、循环、竖向或方形、模板包以及自带声音的图标。只构建可见的内容，因此包含数千项的素材库也能流畅滚动。卡片渲染后即可作为拖移来源。
- **检查器**，从播放控制行的三个按钮升起、覆盖在结果上方的抽屉：**参数**（模板自身的设置，按图形的各部分组织，带撤销和已存储的预设）、**输出**（预设、画面比例和分辨率、帧速率、修剪、遮罩、字幕、文件存放位置）和 **信息**（项目是什么、其标签、主题和许可证）。图钉可在你选择其他项目时保持它打开。
- **收集栏**，位于底部，仅在有内容时显示在窗口中：浏览时收集的项目，各有自己的输出设置，可重新排序、存储为文件、一起渲染。已完成的渲染是一张卡片，可直接拖入剪辑软件。
- **播放控制行**，位于最下方：播放、逐帧、循环、入点和出点标记、时间码、音量和响度表、与窗口同宽的擦洗条，其下方是每个图层一条的条形，**画面轨道** — 叠加在镜头上的片段，在某个时刻放入以实现画中画或 B-roll，然后移动、调整大小、裁剪和加边框 — 以及剪辑轨道 — 作品的镜头首尾相接，每个镜头都有右键菜单，可设置其转场、声音、**速度**（一个速率、两个速率之间的渐变、平滑慢动作），以及在播放头处的 **定格帧**。每条轨道在左侧标有名称——**图层**、**画面**、**剪辑**；画面轨道在放入片段之前不占空间：把片段拖到轨道上方，它会以高亮的放置轨道出现。状态项 — 项目、FFmpeg、素材库的数量、渲染缓存 — 位于其按钮行的末尾。
- **开始屏幕**，启动时以及从“文件 → 主页”打开时覆盖在窗口上：最前面是 **新建项目**（旁边是“打开”，四种形状以图块显示，平台以一个列表显示），然后是“继续”（你最近的项目）、“从创意开始”（制作选项和示例，一个由真实图片组成、随指针擦洗的图库）和“学习”。首次启动时最前面是设置清单及其进度；设置完成后，清单移至 **帮助 → 设置清单**。开始屏幕采用窗口的外观。

每个区域都可以通过边缘的分隔条调整大小，通过标题中的箭头折叠，并在会话之间记住这两者。**影院模式**（`T`）会隐藏结果，让舞台占满窗口；**弹出舞台** 会将画面放到第二台显示器上。

**浅色或深色：** **设置 → 外观** 或 **视图 → 外观** — 跟随系统（默认，随电脑设置的变化而变化）、浅色或深色。所有窗口会立即改变，Pulp 下次也会以此外观打开。透明图形背后的棋盘格（在舞台上以及结果中其卡片背后）在浅色模式下更亮；你为舞台选择的背景 — 黑色、白色、灰色或自选颜色 — 以及模板绘制的内容在两种模式下看起来都一样，因此要对照固定颜色判断图形时，请选择其中一种。

## 制作内容

1. **为 Pulp 提供素材库。** 文件 → 添加 → 你的媒体文件夹… 会在原位置为文件夹建立索引，不会拷贝或移动任何内容。添加 → 示例媒体 会写入一个包含原创 CC0 片段、静帧、声音和音乐的文件夹，供你练习使用。从一开始就有四百多个内置模板。
2. **查找模板。** 在搜索框中输入，或在树中选择一个类别。指针悬停时卡片会擦洗预览。
3. **进行设置。** 打开 **参数**，填写文字、颜色和标志。用“添加图层”添加你自己的文字行，并在舞台上将其拖到想要的位置。
4. **选择形状和格式。** 在 **输出** 中：平台预设（TikTok、Reels、YouTube 等）可一次性设置画面比例、尺寸、速率和编码器，也可以自行设置。ProRes 4444 和 WebM VP9 保留透明度；H.264 MP4 用于发布；DNxHR HQ 和 HQX 适用于 Avid 及其他偏好 DNxHR 的剪辑软件。若用于网页或聊天、无需剪辑软件，**GIF**（叠加在背景色上，调色板专为片段生成）、**WebP 动图** 和 **APNG**（均保留透明度）会无限循环；它们有各自的 **动图帧率** 和 **动图宽度**，因为帧数和像素越少，文件越小——GIF 默认每秒 15 帧、宽 480 像素。
5. **渲染**，点按按钮或按 Cmd/Ctrl+R。渲染会出现在收集栏中。
6. **交付。** 将已完成的卡片拖入剪辑软件，或使用“共享…”和“打开上传页面”。

一次会话会存储为 `.pulp` **项目**（Cmd/Ctrl+S），包含它用到的一切：模板、图层、剪辑轨道、声音和字幕。

## 值得了解的按键

完整列表（与菜单中实际一致）见 **帮助 → 键盘快捷键** — 以下是最常用的。macOS 上用 Cmd，其他系统用 Ctrl。

| 按键 | 作用 |
|---|---|
| `Cmd/Ctrl+F` | 从任何位置将插入点放到搜索框中 |
| `Cmd/Ctrl+N`, `O`, `S` | 新建项目、打开、存储 |
| `Cmd/Ctrl+1`, `2`, `3` | “参数”、“输出”和“信息”抽屉 |
| `Cmd/Ctrl+Shift+1`…`4` | 显示或隐藏浏览面板、预览、结果、收集栏 |
| `Cmd/Ctrl+Return` | 播放或暂停 |
| `Cmd/Ctrl+Shift+,` 和 `.` | 上一帧和下一帧 |
| `Cmd/Ctrl+Shift+I` / `O` | 设置入点和出点标记 |
| `Cmd/Ctrl+R` | 渲染；`Cmd/Ctrl+Shift+R` 渲染整个合集 |
| `Cmd/Ctrl+B` | 在播放头处拆分剪辑 |
| `Cmd/Ctrl+Z`, `Shift+Z` | 撤销和重做参数或图层编辑 |
| `T` | 影院模式：舞台占满窗口 |
| `Esc` | 关闭抽屉、对话框，或停止正在播放的内容 |

**不用指针。** 每个区域都可以用 Tab 键到达，并用箭头键操作。一组控件是一个 Tab 停靠点，箭头键在组内移动：筛选标签和检查器的标签页用左右键切换，浏览树用上下键（右键展开节点，左键折叠或退出），结果以网格方式用箭头键移动 — 横向一张卡片，纵向一行，Page Up 和 Page Down 按屏翻动，Home 和 End 到两端 — 收集栏的卡片用上下键，按 Enter 在文件管理器中显示渲染。分隔条可用箭头键调整大小。获得焦点的元素总会显示一个环。

## 搜索

自由文本匹配名称、标签和主题；多个字词必须全部匹配。双引号可将字词组合为短语。`key:value` 形式的搜索词可缩小范围：

| 搜索词 | 查找 |
|---|---|
| `tag:news` | 带有此标签的项目 |
| `type:wipe` | 分类类型、类型组（`type:sfx`），或 `template`、`media`、`video`、`image`、`audio` |
| `theme:wedding` | 主题；组名可找到其下的所有内容 |
| `style:grunge` | 声明此风格的模板 |
| `mood:calm` | 按感觉查找音效和音乐：upbeat、calm、dramatic、epic、tense、playful、melancholy、mysterious — 来自以其命名的文件夹，或文件自身的流派、情绪或注释标签 |
| `category:title` | 模板类别 |
| `pack:newsdesk` | 来自某个模板包的模板；`pack:any` 表示任意模板包 |
| `duration:>5` | 秒数；支持 `<`、`>`、`<=`、`>=`、`=` 以及 `5-10` 这样的范围 |
| `width:>=1920`, `height:1080`, `fps:29.97` | 对画面进行相同的比较 |
| `res:1080p` | 短边；`4k`、`uhd`、`8k`、`hd`、`fhd` 也可用 |
| `codec:prores` | 视频编解码器，采用 ffprobe 的命名 |
| `alpha:yes` | 透明；`alpha:no` 表示其余项目 |
| `orientation:portrait` | `portrait`、`landscape` 或 `square`；模板的任一形状符合即匹配 |
| `favorite:yes` | 收藏；`favorite:no` 表示其余项目 |
| `recent:yes` | 你用过的内容，最近的在前；`recent:10` 表示最近十个 |

`type:lower-third theme:news duration:<8` 同时使用了其中三个。同样的语法适用于所有选择器 — 图片和片段选择器、舞台的素材列表 — 而不仅限于搜索框。

## 你的内容在哪里

- **双击项目文件即可在 Pulp 中打开**，无论是从文件管理器还是从程序坞；已打开的 Pulp 会在自己的窗口中接收它，并先询问未存储的更改。
- **你的媒体保持原位。** Pulp 在原位置为文件夹建立索引，从不移动或拷贝其中的内容，但你导入的图片和字体除外，它们会被拷贝到受管理的文件夹中，以免项目丢失它们。
- **素材库在原处读取。** **添加 → 素材库…** 可指向一个文件夹、驱动器或已挂载的光盘，其中是你持有许可的素材；**添加 → 从光盘映像添加库存素材库…** 可选择尚未挂载的 `.iso` 或 `.dmg`，以只读方式挂载并列出其中内容——无法挂载时会用系统自身的话明确说明。其中任何内容都不会被拷贝、移动或写入；Pulp 了解到的信息（缩略图、时长）保存在 Pulp 自己的数据中。驱动器未连接时，素材库仍会列出并显示**未连接**，驱动器接回后自动恢复，收藏和标签保留。庞大的素材集可以立即浏览：Pulp 读取其自带的小预览和缩略图，至多再读取每个文件的文件头（获取尺寸和透明度），只有在放置或渲染时才读取完整文件。素材集自带的目录（`catalog.csv` 或 `catalog.json`）会被读取，其类别映射到 Pulp 的类别，分区显示在素材库节点下。片头、循环和片尾是一个可拉伸到任意长度的**片段组**；多个时长的音轨是一个项目，自动选用合适的版本；歌曲的分轨是一个项目，每个分轨一条通道。压缩包无需解压即可浏览（**压缩包内**），其中的文件只在使用时解压——解压到压缩包旁边，或在驱动器只读时解压到 Pulp 自己的数据中。Pulp 无法读取的内容（After Effects 项目、光盘映像、受密码保护的压缩包）会列出并说明需要什么。
- **素材始终属于你。** 它们在原处被引用，绝不会发送到任何地方，也绝不会被拷贝到模板包、导出的剪辑或项目中；仓库中的测试（`tests/stock-rights.test.ts`）确保 Pulp 遵守这一点。
- **一键录制语音。** 素材库工具中的麦克风按钮（或 **文件 → 录制音频**，Cmd/Ctrl+Shift+A）会立即用系统麦克风开始录制；一个条带显示电平和时间；再次点按按钮、点按其“停止”或按 Escape 即可结束本次录制。录音会以 WAV 格式存入 Pulp 自己的 **Recordings** 文件夹，按日期和时间命名，加入素材库并被选中、随时可用，在任何能使用声音的地方都能使用 — 剪辑轨道上、模板中、渲染中、拖入剪辑软件中。按钮旁的小菜单可选择使用哪个麦克风并记住它；麦克风中途失效时，已录内容会保留。首次录制会请求系统的麦克风权限；如果被拒绝，条带会说明情况并提供前往设置的途径。
- **有人说话时音乐自动压低。** 在音乐图层的设置中，**人声时压低** 选择正在说话的音频图层——一段录音或旁白。说话时音乐按 **压低**（默认 12 dB）降低，说完后恢复；**压低速度** 是压低所需的时间，恢复需要两倍时间。压低会在第一个字之前略早开始，并在短暂停顿中保持，因此音乐不会在句子之间忽高忽低。预览中听到的压低与渲染结果一致，响度表也会计入。
- **手机拍摄的 HDR 片段会自动转换。** 手机以 HDR 录制的片段（PQ 或 HLG，Pulp 从文件自身的标记读取）在素材库中带有 **HDR** 标记，信息标签页的 **范围** 一行会说明它将如何处理。凡是 Pulp 绘制或写出它的地方——舞台、剪辑轨上的镜头、图层、渲染——都会转换为标准范围，看起来和手机上一样，而不是发灰发平。**文件本身绝不会被改动：** 只会被读取，HDR 仍然保留，可用于其他用途。这需要带 zimg 的 FFmpeg；没有的话，片段会按原样播放和渲染，信息标签页和渲染都会说明这一点以及该怎么做。
- **一键用摄像头录制。** 麦克风旁的摄像头按钮（或 **文件 → 录制视频**）会打开系统摄像头带声音的实时预览；**录制** 开始录制，画面上会显示已录时间，再次点按“录制”（此时显示为“停止”）、按 Escape 或点按“关闭”即可结束。录制内容会存入 **Recordings** 中，与语音放在一起，按日期和时间命名，格式为 MP4（H.264 和 AAC），采用摄像头自身的尺寸和稳定的帧速率，所有剪辑软件都能打开；它会加入素材库并被选中，像其他片段一样带有封面图和悬停擦洗。预览的 **摄像头** 和 **声音** 菜单可选择使用哪个摄像头和麦克风，或选择 **无声音**，并记住所选项。朝向你的摄像头会以镜像显示，就像镜子照出的面孔；文件本身从不镜像。首次使用时，系统会请求摄像头权限，开启声音时还会请求麦克风权限；如果任一被拒绝，预览会说明情况并提供前往设置的途径。转换需要 FFmpeg（设置 → FFmpeg 可以获取它）；没有它时，录制内容会保留为窗口录制的 WebM，Pulp 可以播放，但剪辑软件可能无法打开。
- **为竖屏而做。** 二十二个模板首先为竖向画面设计，而不是横向绘制后再适配：可在 **快速访问 → 竖屏专用** 下找到，或搜索该标签。当作品为竖向时 — 从开始屏幕新建的 9:16 项目、TikTok 等平台，或在“输出”标签页中选择了 9:16 — 它们会排在结果前面，并且选中其中一个时，舞台会显示短视频应用覆盖在竖向画面上的区域（**标题安全区域和动作安全区域** 按钮可在本次会话中将其关闭）。六个 **吸睛标题**（Hook Bold、Question、Keyword、Bar、List 和 Quote）是用于第一秒的大标题，以大字号放在上方三分之一处。四种 **字幕样式**（Caption One Word、Duo、Sticker 和 Beside）位于画面中部，或刚好在应用显示自身字幕的位置上方，并突出显示所说的字词；Caption Beside 会询问面孔在哪一侧以及有多高。四种 **画面布局** 用于安排画面：一个横向片段，后面以其自身的模糊画面填满整帧；两个片段上下堆叠；全帧片段上方角落里有一张面孔（面孔是片段图层，因此可在舞台上移动和调整大小）；以及一个带字幕卡的片段。八个 **叠加** — 进度条、分段标签、列表计数器、聊天气泡、评论回复、投票、关注提示和地点标签 — 会避开应用的按钮。每种元素应放在哪里以及原因，见 `docs/vertical-layouts.md`。
- **窗口的语言** 跟随系统，除非你在 **设置 → 语言** 中选择一种：English (US) 或 English (UK)，每种语言都以其自身名称列出。更改会立即显示，菜单也包括在内。本指南也会随之改变。模板所写的内容、其名称及其设置的名称属于其作者，保持原样；你在搜索框中输入的筛选词（`favorite:`、`type:`）也是如此。
- **设置、素材库索引、渲染缓存和日志** 位于 Pulp 自己的文件夹中，与其他应用程序的数据放在一起。**设置…**（Cmd/Ctrl+,）包含你可以更改的内容；状态项中的 **拷贝诊断信息** 会将相关事实、性能部分（素材库有多大、扫描和搜索用了多久、Pulp 的进程占用多少资源）以及日志的最后几行放到剪贴板上，用于错误报告，你的个人文件夹会写为 `~`。
- **FFmpeg 是一个独立的程序**，Pulp 运行它来编码渲染的内容，但不随附它。Pulp 会找到你安装的 FFmpeg，无论是在你的路径中还是在 `PULP_FFMPEG_PATH`。如果你没有，**设置 → FFmpeg** 会提供获取：在获取任何内容之前，它会说明是哪个版本、来自哪个发布者、有多大以及采用什么许可证，将下载内容与公布的校验和核对，并保存在 Pulp 自己的文件夹中 — 这里是最后查找的位置，因此你自己的 FFmpeg 总是优先（决策记录 0022）。
- **中途中断的渲染绝不会被误认为已完成。** 渲染期间，文件名为 `name.partial.mp4`；只有完整时才会使用真正的名称。如果 Pulp 在渲染中途关闭，下次启动时会删除不完整的文件，并提供重新渲染到同一位置的选项。
- **Pulp 面板可以放在 Premiere Pro 或 DaVinci Resolve Studio 中**，无需离开剪辑即可列出此素材库和合集 — 还可以拖入其中：一行内容会按需以项目自身的输出设置渲染（保留 Alpha），然后放入素材箱、放到时间线上，或用于拖移；**打开** 会在 Pulp 中打开它以进行更改，Pulp 的渲染队列在运行时也会显示在面板中。只有在 **设置 → 提供剪辑软件面板服务（本地）** 开启时（默认关闭）才会提供服务，且仅限本机（127.0.0.1），每个请求都需要携带设置旁文件中的令牌。安装面板：[editor-panels.md](editor-panels.md)。
- **不会向任何地方发送内容。** Pulp 发出的请求仅限于你明确要求的那些：用于字幕的语音模型（决策记录 0021）、语义搜索模型（决策记录 0024），以及在你没有 FFmpeg 时获取的 FFmpeg 版本。
