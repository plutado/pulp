    Batch from CSV

    One render per row. Column headers match a parameter id or label (any case); a file (or name, when that is not a parameter) column names the jobs and files.

    Drag to editor

    Editors link to the dragged file rather than copying it. Keep prepared renders in the cache while a project uses them: clearing the cache, or the cache evicting old files, takes those clips offline in the editor.

    Render cache

    Clearing or shrinking the cache removes files that editor projects may link to; those clips go offline there.
