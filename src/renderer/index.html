                Settings

                What the window remembers between sessions, kept beside the library in your settings file. Every control here is the same setting the rest of the window reads.

                Appearance

                How the window looks — every window, the start screen and the dialogs at once. The stage’s checkerboard follows it too; a chosen black, white, gray or custom background and what a template draws stay as they are. Also in View → Appearance.

                Semantic search

                Search by meaning as well as by words: “something calm for a podcast intro” finds the right templates. Off by default. Everything runs on this machine — the library is embedded locally and so is every search; the one thing ever fetched is the model file itself, from its publisher, after you say yes here.

                Editor panel

                A Pulp panel inside Premiere Pro or DaVinci Resolve lists this library and collection without leaving the editing app. Off by default. On, Pulp answers on this machine only (127.0.0.1), and only requests carrying the token from a file beside your settings — nothing is sent anywhere. Installing the panels is described in docs/editor-panels.md (Help → User Guide links it).

                FFmpeg

                Pulp finds FFmpeg on your path, or where the PULP_FFMPEG_PATH environment variable points, when it starts. Renders need it; the rest of Pulp does not.

                Render cache

                Renders prepared for dragging into an editor are kept here. An editor links to the file rather than copying it, so clearing the cache, or the cache dropping its oldest files, takes those clips offline there.

                Remove silences

                The quiet stretches of the track's sound, found before anything is cut: they shade on the track below, and one edit cuts them all — one undo step.

                Transcribe speech

                The speech model runs on this machine and nothing of your project is sent anywhere. The model file itself is fetched once, from its publisher, checked against its checksum and kept beside your settings.

                Key out a color

                The color becomes transparency and its cast is washed from what remains. Pick it from the frame on the left, or choose it below; the result is written beside the original as an alpha clip, its sound kept.
